# {{品类}}重点商品经营周报（{{周期}}）

## 一、本周结论
用 3 句话写最重要的变化：整体表现、最大的问题、最大的机会。

## 二、核心指标
表格：重点商品池 GMV、访客数、支付转化率、客单价，本周值、上周值、环比。

## 三、商品表现
- 增长 Top 3：商品、GMV、环比、原因（一句话）
- 下滑 Top 3：商品、GMV、环比、原因（一句话）
- 健康度变化：从健康掉到关注或风险的商品

## 四、本周预警与处置
按严重度统计问题卡数量；每张问题卡写一行：问题 → 原因 → 方案 → 状态。

## 五、动作效果
已执行动作的前后对比：动作、执行日、跟踪指标、执行前、执行后、变化。注明这是前后对比，不等同于严格的因果效果。

## 六、下周关注
风险商品、断货风险、增长机会，各写明建议的第一步动作。

写作要求：
- 所有数字只能来自周报数据包，不自行计算新数字。
- 用业务语言，不出现字段名。
- 没有数据的部分写「本周无」，不编造。
